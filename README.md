# Duplicater — Pro Disk Optimizer v3.5

Настольное приложение для Windows (Python + [Flet](https://flet.dev)) для поиска и
безопасного удаления дубликатов файлов, похожих изображений и накопившегося мусора.

## Возможности

- **Поиск дубликатов** — многопоточное сканирование выбранных дисков/папок.
  Турбо-режим (быстрый хэш + обязательная проверка полным SHA-256 при совпадении),
  фильтры по размеру и маскам имён, SQLite-кэш хэшей (WAL) для мгновенного пересканирования.
- **Похожие фото** — перцептивные хэши (dHash): находит визуально похожие изображения
  даже с разными именами и размерами.
- **Поиск по образцу** — «найди все копии этого файла» по полному хэшу с префильтром по размеру.
- **Сравнение папок** — уникальные файлы каждой стороны + общие, с бейджами «новее»/«больше».
- **Клинер мусора** — пустые папки, битые ярлыки (.lnk), файлы мусора; удаление в корзину
  по подтверждению.
- **NTFS-хардлинки** — замена дубликатов жёсткими ссылками без потери путей (только для
  байтово-идентичных файлов, с откатом при сбое).
- **Безопасность данных**: подтверждение перед каждым удалением, опция «в корзину»
  (безвозвратное удаление только по явному выбору), журнал операций с отменой
  (`operations_log.json`), защита групп «оригинал + копии» от выделения целиком.
- **История и статистика** сканирований, экспорт результатов в CSV/JSON/TXT.
- Интерфейс **RU/EN**, тёмная/светлая темы.

## Требования

- Windows 10/11, Python 3.10+ (проект собирается и тестируется на 3.14).
- Зависимости — в [`requirements.txt`](requirements.txt) (точные версии), dev-инструменты
  (pytest, ruff, pyinstaller) — в [`requirements-dev.txt`](requirements-dev.txt).

## Запуск

```bat
python -m venv venv
venv\Scripts\pip install -r requirements-dev.txt
venv\Scripts\python main.py
```

или просто `BUILD.bat` → пункт `[1] Run Application`.

В аргументах командной строки можно передать стартовые каталоги:
`python main.py D:\Photos E:\Backup`.

## Тесты и линт

```bat
venv\Scripts\python -m pytest tests/ -q
venv\Scripts\python -m ruff check .
```

Тесты полностью изолированы: работают только во временных каталогах pytest
(`tmp_path`) и перенаправляют рабочие данные через переменную окружения
`DUPLICATER_DATA_DIR` — реальные файлы пользователя не сканируются и не изменяются.

## Сборка портативного EXE

```bat
BUILD.bat
```
(пункт `[2] Build Portable EXE`) — эквивалентно команде:

```bat
venv\Scripts\python -m PyInstaller --noconfirm --onefile --windowed --collect-all flet --name Duplicater main.py
```

Готовый файл: `dist\Duplicater.exe` — работает на любом Windows-ПК без установленного Python.

## Где хранятся данные приложения

| Файл | Назначение |
|---|---|
| `scan_cache.db` | SQLite-кэш хэшей (ускоряет повторные сканирования) |
| `operations_log.json` | журнал операций удаления/хардлинков (основа для «Отменить») |
| `scan_history.json` | история сканирований |
| `duplicater.log` | журнал работы приложения (ротация ~1 МБ × 3) |

- При запуске из исходников — в каталоге проекта.
- В собранном EXE — `%LOCALAPPDATA%\Duplicater`.
- Переопределяется переменной окружения `DUPLICATER_DATA_DIR` (используется тестами).

## Структура проекта

```
main.py               — точка входа, окна/вкладки, фоновые воркеры
scanner.py            — сканирование, хэши, группы дубликатов, сравнение папок
phash_scanner.py      — перцептивные хэши изображений, кластеризация похожих
sweeper.py            — пустые папки, битые .lnk, файлы мусора
hardlink_manager.py   — NTFS-хардлинки с проверкой идентичности и откатом
db_cache.py           — потокобезопасный SQLite-кэш хэшей
ops_log.py            — журнал операций и отмена (undo)
locales.py            — RU/EN переводы
app_logging.py        — файловое логирование
ui/                   — представления Flet (search, results, sample, compare, sweeper)
tests/                — pytest-тесты (изолированные, tmp_path)
```

Подробности проведённого аудита и статус всех найденных проблем — в [`AUDIT_REPORT.md`](AUDIT_REPORT.md);
история изменений — в [`CHANGELOG.md`](CHANGELOG.md).
