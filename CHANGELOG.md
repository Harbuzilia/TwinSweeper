## 2026-09-18 — Раунд 3 аудита: гарантия «не удалит не-дубликат», ревизия тестов на фейковость, 343 теста, v3.6

Финальный раунд по требованию «закрой проект на 100%». Два независимых ревиз-агента (безопасность данных + свежий код) + личная верификация чтением кода. Найдена и закрыта **критическая дыра потери данных** (устаревший хэш в кэше подменял SHA-256-верификацию). Отдельно проведён аудит качества тестов: ~17 мёртвых/слабых тестов переписаны или удалены. Коммиты: `b123f5d` → `02ae1e3` → `bf982bd` → `e63480a` → `fd011bd`.

### Блок 0 — ревизия тестов (по требованию «тесты не должны быть фейковыми»)
- Удалены 2 теста без assert; переписаны: изоляция data-dir (нормализация + позитивный контроль), кэш (счётчик реальных перехэширований вместо сравнения результатов), cache-hit миниатюр (удаление источника доказывает чтение из кэша), плейсхолдеры локалей (string.Formatter, ловит и `{0}`), cancel-тест (детерминированный барьер Event вместо sleep+порога), экспорт (все 4 формата по структуре, включая BOM CSV), assert-free smoke-тесты получили реальные проверки.
- **Правило:** каждый новый тест обязан падать при откате фикса. Для A1 доказано revert-check'ом.

### Блок A — корректность определения дубликатов
- **db_cache.py** — `save_file_hash`: хэш валиден только для тех (size, mtime), с которыми вычислен (`CASE WHEN changed THEN NULL` вместо `COALESCE`). Устаревший full_hash больше не «подтверждает» отредактированный файл как дубликат своего старого содержимого. `get_file_hash(turbo=True)` не возвращает full_hash.
- **scanner.py** — индексация по `(st_dev, st_ino)`: хардлинки/junction-алиасы/перекрывающиеся корни не образуют фантомную пару «дубликатов» (удаление одного уничтожило бы и «оригинал»). `$Recycle.Bin`/`System Volume Information` вырезаются из обхода; в junctions не спускаемся. `scan_for_sample` исключает алиасы образца по inode.
- **main.py** — `perform_delete`: «в корзину» без send2trash → отказ (НЕ тихий `os.remove`); журнал пишется в `finally` (отмена середины не теряет undo). `content_verified` пробрасывается в ResultsView.
- **ui/results_view.py** — сканы без проверки содержимого (только размер/имя) не предвыделяются + баннер предупреждения.
- **ui/components.py** — `get_styled_dialog(content=None)` (два обработчика настроек падали с TypeError после реальной работы).

### Блок B — корректность деструктивных операций
- **ui/sweeper_view.py** — C2-верификация каждого файла перед удалением (снапшоты скана); `verify_file_unchanged` перенесён в scanner.py (общий).
- **ui/results_view.py** — `_do_move` вызывает `_protect_originals` (перемещение не увозит группу целиком).
- **main.py** — `perform_move`: same-volume атомарный `os.replace`; cross-volume — копия проверяется, источник удаляется после неё, при сбое удаления источника копия откатывается; резервирование имени `O_CREAT|O_EXCL`.
- **ops_log.py** — undo: файловые операции вне `_lock` (История не фризит); `undone=True` только при полном успехе (частичный сбой повторим).
- **hardlink_manager.py** — восстановление orphaned-backup после краша между rename; уже-слинкованная пара не журналируется.
- **main.py** — `load_history` валидирует `isinstance(list)`.

### Блок C — качество результатов и UX
- **phash_scanner.py** — complete-linkage кластеризация (цепочки A~B~C не сливают непохожие фото); `.avif` поддержан; отчёт о неподдерживаемых форматах до early-return; финал локализован.
- **sweeper.py / ui/sweeper_view.py** — `.bak/.dmp/.old` и >100 МБ не предвыделяются; битые ярлыки пропускаются при недоступном диске цели; .lnk декодируется вариантом, при котором путь существует (mbcs→utf-8, без lossy-фабрикации).
- **scanner.py / phash_scanner.py** — exclude-паттерны с разделителями матчатся как префикс пути.
- **ui/** — `status_icon.name`→`.icon` (flet 0.86); compare busy-guard; set_mode блокируется во время скана; run-generation защита от затирания UI; контекстное меню остаётся в настройках; trash_default «живой»; невалидный min size подсвечивается; 0-байтные группы не предвыделяются; уникальное имя tmp миниатюр.

### Блок D — длинные пути >260
- **scanner.py** — `long_path()` добавляет `\\?\` только для путей >MAX_PATH (обычные не меняются); применён к get_file_hash/get_turbo_hash/compare_byte_by_byte/compute_dhash. Деструктивные операции сохраняют обычный путь → C2 безопасно отказывает на >260.

### Верификация
- `pytest`: **343 passed**; `ruff check`: **0**; `compileall` + import-smoke 17 модулей: без ошибок.
- MD5 `scan_cache.db*`, `operations_log.json`, `scan_history.json` — совпадают за все три раунда.
- `dist/Duplicater.exe` пересобран (26.6 МБ).
- **Вердикт:** при обычном использовании (скан диска → удалить выбранное в корзину) программа НЕ может удалить не-дубликат — все три цепочки, пробивавшие защиту, закрыты.
- **Почему:** закрытие последней критической дыры потери данных и доведение гарантий корректности до уровня «можно запускать по всем дискам без страха».

## 2026-09-16 — Полный аудит: 19 фиксов (3 критических, 5 высоких, 10 средних, 1 низкий), 224 теста, инфраструктура

Итог полного аудита кодовой базы. Каждое исправление — по схеме «подтверждение кодом → фикс → регрессионный тест»; все тесты изолированы (`DUPLICATER_DATA_DIR` + `tmp_path`), пользовательские данные не затронуты (контрольные MD5 до/после совпадают). Подробности: `AUDIT_REPORT.md`.

### Критические (потеря данных)
- **C1** `hardlink_manager.py`, `ui/results_view.py` — хардлинк визуально похожих (не идентичных) фото больше невозможен: кнопка скрыта для pHash-результатов (`allow_hardlink=False`) + обязательная проверка size и полного SHA-256 в `replace_with_hardlink`.
- **C2** `main.py` (`verify_file_unchanged`), `ui/results_view.py` — TOCTOU: перед удалением/хардлинком воркер сверяет актуальные size/mtime со снимком сканирования, при расхождении файл пропускается с ошибкой.
- **C3** `ui/results_view.py` — «Выделить всё»/«Инвертировать» больше не стирают группу целиком: `_protect_originals` защищает оригинал в полностью выделенных группах, диалог показывает число защищённых групп.

### Высокие
- **H1** `ui/compare_view.py` — вью приведён к реальной схеме `compare_folders` (`file_a/file_b/similarity/newer/larger`) — вкладка «Общие файлы» больше не падает с KeyError.
- **H2** `main.py` — `EMPTY_COMPARE_RESULT` повторяет реальную схему сравнения папок; ошибка показывается в UI вместо зависшего прогресса.
- **H3** `main.py` — все фоновые воркеры и undo переведены на `page.run_thread` (корректный контекст страницы в flet 0.86.5).
- **H4** `ui/sweeper_view.py`, `sweeper.py` — очистка мусора: диалог подтверждения, опция «в корзину», журнал операций; `desktop.ini` убран из мусора; пустые папки только через `os.rmdir`.
- **H5** `main.py`, `ui/sweeper_view.py` — сбой `send2trash` больше не превращается в безвозвратное удаление: файл остаётся, ошибка показывается.

### Средние
- **M1** `hardlink_manager.py` — `WinDLL(..., use_last_error=True)` + `argtypes`: корректные коды Win32-ошибок.
- **M2** `scanner.py` — `is_system_path` матчит целые компоненты пути от реальных системных корней (не подстроки).
- **M3** `phash_scanner.py` — уникальные ключи групп pHash (кластеры не теряются по имени).

- **M6** `hardlink_manager.py` — зачистка остатков `.tmp_hl_*`, честный учёт освобождённого места.
- **M7/M7b** `ops_log.py`, `main.py` — undo: копия во временное имя → атомарная замена (файл не исчезает при сбое); выполняется в фоне.
- **M8** `main.py` — при ошибке сканирования ранний return (без ложного «Дубликаты не найдены»).
