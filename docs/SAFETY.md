# Безопасность данных: 10 гарантий корректности

TwinSweeper удаляет и перемещает файлы на вашем диске, поэтому главный принцип
проекта звучит так: **программа не может удалить или переместить файл, который не
является настоящим дубликатом**.

Ниже — полный список механизмов, которые это обеспечивают. Каждый из них покрыт
тестами (`tests/`, 433 проверки) и не является «намерением в документации»:
инварианты проверяются на реальном поведении кода.

## 10 гарантий

1. **Содержимое проверяется полностью.** В турбо-режиме быстрый хэш (первые/последние
   64 КБ) только отбирает кандидатов; каждая группа затем подтверждается полным
   SHA-256 всех файлов. Совпал размер, но не содержимое — файлы НЕ дубликаты.
2. **Кэш хэшей не устаревает.** Хэш в кэше привязан к (размер, mtime) файла: если файл
   изменили, старый хэш сбрасывается и пересчитывается. Отредактированный файл не
   будет «подтверждён» как дубликат своего прежнего содержимого.
3. **Один физический файл не считается дубликатом.** Хардлинки, junction-алиасы и
   перекрывающиеся папки сканирования распознаются по (устройство, inode) — удаление
   «дубликата» не уничтожит «оригинал», потому что это один и тот же файл.
4. **Системное и корзина исключены.** `$Recycle.Bin`, `System Volume Information` не
   индексируются: удалённая ранее копия не может стать «оригиналом» и пометить живой
   файл «дубликатом».
5. **Перепроверка перед удалением (TOCTOU-защита).** Непосредственно перед удалением/
   хардлинком/перемещением файл сверяется со снимком скана (размер, mtime). Изменился
   — операция пропускается с ошибкой, файл остаётся.
6. **Группа не исчезает целиком.** Правила «выделить всё»/«инвертировать» и удаление
   гарантируют: в каждой группе остаётся минимум одна копия («оригинал» защищён).
7. **Корзина — значит корзина.** Если «удалить в корзину» выбрано, но корзина недоступна,
   файл НЕ удаляется (никакого тихого безвозвратного удаления). Сбой корзины = ошибка.
8. **Сканы без проверки содержимого** (только по размеру/имени) не предвыделяют файлы
   и показывают предупреждение.
9. **Похожие фото (pHash) — не дубликаты.** Они не предвыделяются к удалению, кнопка
   хардлинка скрыта, а кластеризация complete-linkage не сливает заведомо разные кадры.
10. **Каждая операция обратима.** Удаление/хардлинк/перемещение пишутся в журнал
    (`operations_log.json`) с возможностью отмены — даже если операция была прервана.

## Остаточные ограничения

Ограничения честно описаны в [`../AUDIT_REPORT.md`](../AUDIT_REPORT.md):

- миллисекундное окно между перепроверкой и самим удалением (файл может измениться
  в этот момент — крайне узкое окно, полностью закрыть его на NTFS без потери скорости
  нельзя);
- глубокие пути >260 символов зависят от системной настройки ОС (длинные пути).
