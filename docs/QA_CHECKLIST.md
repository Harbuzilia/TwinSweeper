## Исходный чеклист (для ручного прогона)

**Правила прогона:** на собранном EXE из CI-релиза; все операции — только в
tmp-песочнице (`%TEMP%\tws_qa`), env `DUPLICATER_DATA_DIR` → tmp. Реальные
данные пользователя не задействуются. Каждый пункт: шаги → ожидание → PASS/FAIL.

Подготовка песочницы: 3 одинаковых файла (дубликаты), 2 похожих изображения,
1 уникальный файл, пустая папка, вложенные пустые папки, битый .lnk, .tmp-файл.

## Гарантии безопасности (README / docs/SAFETY.md)

| # | Проверка | Ожидание | Статус |
|---|----------|----------|--------|
| 1 | Удаление выбранных дубликатов | Показан диалог подтверждения ДО операции; без подтверждения ничего не происходит | ☐ |
| 2 | Удаление с опцией «в корзину» | Файлы в корзине Windows; восстанавливаются штатно | ☐ |
| 3 | Сбой корзины (заблокированная/недоступная корзина) | Операция прерывается с ошибкой; безвозвратного удаления НЕ происходит | ☐ |
| 4 | Отмена удаления из журнала | Файлы возвращаются на место | ☐ |
| 5 | Хардлинки + отмена | Дубликат заменён ссылкой (st_nlink=2); undo восстанавливает отдельную копию, в т.ч. если родительская папка удалена | ☐ |
| 6 | Перемещение + отмена | Источник удаляется только после полной копии; undo возвращает файлы; опустевшая папка воссоздаётся | ☐ |
| 7 | Подмена файла между сканом и операцией | Изменённый файл отклоняется с ошибкой, НЕ удаляется | ☐ |
| 8 | «Выделить всё» + удаление | В каждой группе остаётся минимум одна копия | ☐ |
| 9 | «Удалять опустевшие папки» | Пустые родители удалены (rmdir); папка с любым содержимым не тронута | ☐ |
| 10 | Турбо-режим | Группа подтверждена полным SHA-256 (same-size/different-content не группируется) | ☐ |
| 11 | Похожие фото | Ничего не предвыделено к удалению; кнопка хардлинка скрыта | ☐ |
