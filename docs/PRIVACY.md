# Приватность — TwinSweeper

TwinSweeper работает с вашими файлами, поэтому здесь только проверяемые факты:
каждое утверждение ниже можно сверить с кодом (ссылки на файлы — рядом).
Никаких «намерений» — только то, что делает (и чего не делает) программа.

## Коротко

- **Нет сети.** Приложение полностью офлайн: телеметрии, аналитики, сбора
  ошибок, автообновлений, аккаунтов и серверов нет.
- **Нет установки.** Один EXE-файл; фоновых служб и автозапуска нет.
- **Всё локально.** Все данные — несколько файлов рядом с приложением или в
  вашем профиле Windows; их можно удалить в любой момент.

## Сеть: полностью офлайн

В коде приложения нет ни одного сетевого вызова — ни `requests`, ни
`urllib`, ни `socket`, ни `http.client` (проверяется поиском по исходникам:
`grep -rn "requests\|urllib\|socket\|http" --include=*.py` по каталогам
`main.py`, `ui/`, корневым модулям — совпадений сетевого кода нет). GUI
строится на библиотеке flet, которая поставляется внутри EXE и используется
только для отрисовки окна.

Единственное сетевое взаимодействие, связанное с TwinSweeper, происходит вне
приложения: вы сами скачиваете EXE со страницы
[Releases](https://github.com/Harbuzilia/TwinSweeper/releases) в браузере.
Приложение никуда не подключается — в том числе «позвонить домой» ему нечем.

## Что и где хранится

Все данные приложения живут в одном каталоге (`db_cache.get_data_dir()`,
`db_cache.py`):

| Запуск из | Каталог данных |
|---|---|
| EXE (собранное приложение) | `%LOCALAPPDATA%\TwinSweeper` (профиль пользователя) |
| исходников (для разработчиков) | каталог проекта |
| тестов (для разработчиков) | временная папка, задаётся переменной `DUPLICATER_DATA_DIR` |

Состав (`main.py`, `db_cache.py`, `ops_log.py`, `app_logging.py`,
`folder_priorities.py`, `ui/thumbnails.py`):

| Файл / каталог | Что внутри | Зачем |
|---|---|---|
| `scan_cache.db` (+ временные `-wal`/`-shm`) | SQLite: **пути** файлов, размер, mtime, SHA-256-хэши, перцептуальные хэши картинок | ускоряет повторные сканирования |
| `operations_log.json` | **полные пути** удалённых / хардлинкнутых / перемещённых файлов (пары «источник → получатель»), размер освобождённого места; хранятся последние 100 операций | журнал для кнопки «Отменить» |
| `scan_history.json` | параметры прошлых сканирований (папки, тип поиска, итоги) | список «История» |
| `twinsweeper.log` (+ `.1`, `.2`) | журнал работы приложения (ротация ~1 МБ × 3 файла) | диагностика проблем |
| `folder_priorities.json` | список ваших приоритетных папок | правила автовыделения |
| `settings.json` | 3 настройки: язык, тема, «удалять в корзину по умолчанию» — ничего личного | сохранение выбора между запусками |
| `thumbs/` | кэш миниатюр картинок | скорость отображения результатов |

Ни один из этих файлов не покидает ваш компьютер.

## Реестр Windows

По умолчанию приложение **ничего не пишет в реестр**. Единственный
опциональный случай — интеграция с контекстным меню Проводника («Найти
дубликаты в TwinSweeper»): включается и выключается переключателем в
настройках, пишет только в ветку `HKEY_CURRENT_USER\...\shell\TwinSweeper`
(профиль пользователя, не системная ветка). Выключение переключателя удаляет
записи (`main.py`, `unregister_context_menu`).

Удаление приложения = удалить EXE-файл: установщика, служб и следов в
системных каталогах нет.

## Корзина

- По умолчанию удаление идёт **в корзину Windows**: файл восстанавливается
  штатно (правый клик → «Восстановить»), пока корзина не очищена.
- Если корзина недоступна, операция **прерывается** — никакого тихого
  безвозвратного удаления (см. [`SAFETY.md`](SAFETY.md), гарантия 7).
- Альтернатива удалению — «Переместить» в выбранную вами папку.

## Как удалить все следы

1. Закройте приложение.
2. Настройки → **«Очистить базу кэша»** — стирает содержимое
   `scan_cache.db` (инвентарь путей и хэшей).
3. Удалите каталог данных целиком — это удаляет и `operations_log.json` с
   путями удалённых/перемещённых файлов, и миниатюры, и журнал:
   - EXE: `%LOCALAPPDATA%\TwinSweeper`;
   - исходники: перечисленные выше файлы в каталоге проекта.
4. Если включалось контекстное меню Проводника — выключите его в настройках
   (или удалите ветку `HKCU\Software\Classes\Directory\shell\TwinSweeper` и
   `...\Background\shell\TwinSweeper`).
5. Очистите корзину Windows, если в ней оставались удалённые файлы.
6. Удалите сам `TwinSweeper.exe`.

После этих шагов на компьютере не остаётся данных, созданных приложением.
