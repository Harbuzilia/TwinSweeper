# Duplicater — правила работы

1. **После каждого изменения** кода, конфигурации или зависимостей обновляй `CHANGELOG.md`:
   новая запись добавляется сверху (дата → файлы → что изменено → почему).
2. Изменения минимальны и не ломают существующее поведение.
3. Перед заявлением о завершении — проверка: компиляция/импорт модулей, smoke-тест затронутой логики.
